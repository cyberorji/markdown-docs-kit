# markdown-docs-kit

> Markdown dosyalarından aramalı dokümantasyon sitesi üretici

Bu depo aktif geliştirme altındadır. Amaç; Linux, Windows ve Termux üzerinde kolay kurulabilen, açık kaynak ve topluluk katkısına uygun bir başlangıç sunmaktır.

## Durum

**Başlangıç sürümü / scaffold.** Özellikler aşamalı olarak eklenecektir.

## Kurulum

### Linux

```bash
git clone https://github.com/cyberorji/markdown-docs-kit.git
cd markdown-docs-kit
```

### Windows (PowerShell)

```powershell
git clone https://github.com/cyberorji/markdown-docs-kit.git
Set-Location markdown-docs-kit
```

### Termux

```bash
pkg update
pkg install git
git clone https://github.com/cyberorji/markdown-docs-kit.git
cd markdown-docs-kit
```
